# Key of correct answers for `MSATBtest` dataset.

The `MSATBkey` is a vector of factors representing correct answers of
`MSATBtest` dataset.

## Usage

``` r
data(MSATBkey)
```

## Format

A nominal vector with 20 values representing correct answers to items of
`MSATBtest` dataset. For more details see
[`MSATBtest`](https://adelahladka.github.io/difNLR/reference/MSATBtest.md).
