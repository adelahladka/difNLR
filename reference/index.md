# Package index

## Package overview

- [`difNLR-package`](https://adelahladka.github.io/difNLR/reference/difNLR-package.md)
  : DIF and DDF Detection by Non-Linear Regression Models.

## Core functions

- [`difNLR()`](https://adelahladka.github.io/difNLR/reference/difNLR.md)
  : DIF detection using non-linear regression method.
- [`difORD()`](https://adelahladka.github.io/difNLR/reference/difORD.md)
  : DIF detection among ordinal data.
- [`ddfMLR()`](https://adelahladka.github.io/difNLR/reference/ddfMLR.md)
  : DDF detection for nominal data.
- [`genNLR()`](https://adelahladka.github.io/difNLR/reference/genNLR.md)
  : Generates data set based on generalized logistic regression DIF and
  DDF models.

## Helper functions

- [`startNLR()`](https://adelahladka.github.io/difNLR/reference/startNLR.md)
  : Calculates starting values for non-linear regression DIF models.
- [`estimNLR()`](https://adelahladka.github.io/difNLR/reference/estimNLR.md)
  [`logLik(`*`<estimNLR>`*`)`](https://adelahladka.github.io/difNLR/reference/estimNLR.md)
  [`coef(`*`<estimNLR>`*`)`](https://adelahladka.github.io/difNLR/reference/estimNLR.md)
  [`fitted(`*`<estimNLR>`*`)`](https://adelahladka.github.io/difNLR/reference/estimNLR.md)
  [`residuals(`*`<estimNLR>`*`)`](https://adelahladka.github.io/difNLR/reference/estimNLR.md)
  [`print(`*`<estimNLR>`*`)`](https://adelahladka.github.io/difNLR/reference/estimNLR.md)
  [`vcov(`*`<estimNLR>`*`)`](https://adelahladka.github.io/difNLR/reference/estimNLR.md)
  : Non-linear regression DIF models estimation.
- [`formulaNLR()`](https://adelahladka.github.io/difNLR/reference/formulaNLR.md)
  : Creates a formula for non-linear regression DIF models.
- [`MLR()`](https://adelahladka.github.io/difNLR/reference/MLR.md) : DDF
  likelihood ratio statistics based on multinomial log-linear regression
  model.
- [`NLR()`](https://adelahladka.github.io/difNLR/reference/NLR.md) : DIF
  statistics for non-linear regression models.
- [`ORD()`](https://adelahladka.github.io/difNLR/reference/ORD.md) : DIF
  likelihood ratio statistics for ordinal data.
