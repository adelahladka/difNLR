# Key of correct answers for `GMATtest` dataset.

The `GMATkey` is a vector of factors representing correct answers of
generated `GMATtest` data set based on Graduate Management Admission
Test (GMAT, Kingston et al., 1985).

## Usage

``` r
data(GMATkey)
```

## Format

A nominal vector with 20 values representing correct answers to items of
`GMATtest` dataset. For more details see
[`GMATtest`](https://adelahladka.github.io/difNLR/reference/GMATtest.md).

## References

Kingston, N., Leary, L., & Wightman, L. (1985). An exploratory study of

Management Admission Test. ETS Research Report Series, 1985(2): 1–64.
